# Techfest 2026 — An Aetherial Renaissance

A responsive, single-page concept landing page for the 30th edition of Techfest, IIT Bombay.

## Run locally

No build tools or package installation are required. Open `index.html` in a browser, or run a simple local server from this folder:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy on GitHub Pages

1. Create a public GitHub repository.
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for the Pages deployment to finish.

This is a static HTML/CSS/JavaScript project. It does not require Vite, Node, a build step, or a GitHub Actions workflow.

## Implemented interactions

- Responsive navigation with mobile menu
- Smooth in-page navigation
- Competition category filters
- Expandable FAQ accordion
- Scroll-reveal transitions
- Back-to-top button
- Animated SVG celestial illustration

## Content notes

This is an independent student concept landing page, not an official Techfest property. Event dates, competition names, prize amounts and workshop descriptions are presented from publicly available Techfest 2026–27 pages and should be rechecked against the official site before publication. Registration and detailed briefs link to `https://techfest.org/`.
